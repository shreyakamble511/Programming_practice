\## How to Compile and Run



\### C Programs



Compile using GCC:



```bash

gcc program.c -o program

```



Run on Windows:



```cmd

program.exe

```



\### C++ Programs



Compile using G++:



```bash

g++ program.cpp -o program

```



Run on Windows:



```cmd

program.exe

```



\### Java Programs



Compile using the Java compiler:



```bash

javac Program.java

```



Run the program:



```bash

java Program

```



Replace the example filenames with the actual filenames used in your programs. Ensure the required compiler or JDK is installed and configured.
